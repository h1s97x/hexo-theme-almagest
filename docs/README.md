## 这是什么

Almagest 是一个 Hexo 静态博客主题，主打**深空视觉 + 天文组件**：Canvas 星空背景、天文事件日历、观测指南、星座导航，以及一套完整的博客基础能力（本地搜索、代码高亮与复制、图片懒加载、明暗主题切换、多语言）。

主题本身**不是可运行的程序**——它是被 Hexo 站点调用的「插件」。要看到效果必须先有一个 Hexo 站点（见 [08 · 运行方式](08-getting-started.md)）。

## 技术栈一览

| 维度       | 选型                                                                          |
| ---------- | ----------------------------------------------------------------------------- |
| 模板引擎   | **EJS**（`layout/**/*.ejs`，30 个文件）                                       |
| 样式       | **Stylus**（`source/css/*.styl`，13 个文件）                                  |
| 服务端脚本 | **Node.js + Hexo API**（`scripts/**/*.js`，10 个文件）                        |
| 前端脚本   | **原生 ES5/ES6 JavaScript**（`source/js/*.js`，5 个文件，无构建步骤、无框架） |
| 多语言     | **YAML**（`languages/{en,zh-CN,zh-TW}.yml`，3 个文件）                        |
| 环境要求   | Node.js `>= 18`，Hexo `>= 6`（`asset_code` 标签需 Hexo `>= 7`）               |

## 三分钟速览

```
用户浏览器
    │  HTTP
    ▼
┌──────────────────────────────────────────────────────┐
│  hexo generate（构建期）                              │
│                                                      │
│  source/_posts/*.md                                  │
│      │                                               │
│      ├─► scripts/ 注册的 filter / generator /        │
│      │     helper / tag   ← 内容加工                  │
│      │                                               │
│      └─► layout/*.ejs  ← 用模板渲染成 HTML            │
│              │                                       │
│              └─► source/css + source/js  ← 打包资源   │
│                                                      │
│  产物：public/{index.html, post/…, css/main.css,      │
│              js/*.js, search.json}                    │
└──────────────────────────────────────────────────────┘
```

**关键认知**：主题代码在**两个完全不同的时刻**执行——

| 时刻       | 执行者  | 代码位置                                   | 能做什么                          |
| ---------- | ------- | ------------------------------------------ | --------------------------------- |
| **构建期** | Node.js | `scripts/**`、`layout/**`、`source/css/**` | 读文件、生成页面、编译样式        |
| **运行期** | 浏览器  | `source/js/**`                             | 操作 DOM、Canvas 绘制、fetch 检索 |

**两者之间只能通过 HTML 里的 DOM 结构与内联的 `window.__almagest*` 全局变量通信。** 这是排查「功能静默失效」类问题的第一原则：先确认服务端产出的选择器/变量名，与前端脚本要找的是否一致。

## 迭代前请先读

[09 · 实现现状与已知缺陷](09-known-issues.md) 记录了 10 项**已确认存在**的问题，包括：

- 注册了但零调用的 helper（`is_featured` / `get_categories` / `get_tags`）
- 配置开关打开了、但对应前端逻辑不存在（返回顶部按钮）
- 4 个天文组件模板**没有被任何模板引用**（孤儿组件）
- 配置对象被遮蔽导致的路径拼接缺陷（导航 active 态永不生效）
- `docs/DEVELOPMENT.md` 中的文件树与实际不符（文档漂移）

这些不是"待办清单"，而是当前代码的**真实状态**。不了解就直接改，很容易在错误的前提上工作。
