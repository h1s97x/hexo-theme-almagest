# Almagest 设计规范 v2.0

## 设计理念

Almagest 是一款优雅的星空风格 Hexo 博客主题，灵感来自宇宙的深邃与神秘。主题以「单栏居中」为核心布局哲学，追求极简阅读体验，同时保留丰富的可定制能力，让用户能够打造属于自己的数字星空。

## 布局设计

### 整体结构

```
┌─────────────────────────────────────────────────────────┐
│                      Header (固定)                       │
│         Logo            Navigation            Actions    │
├─────────────────────────────────────────────────────────┤
│                                                          │
│                     Main Content                         │
│                    (居中单栏布局)                         │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │                    Banner                        │    │
│  │              (全宽背景 + 标语)                    │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
│  ┌─────────────────────────────────────────────────┐    │
│  │                 Article List                     │    │
│  │                  (文章列表)                       │    │
│  └─────────────────────────────────────────────────┘    │
│                                                          │
├─────────────────────────────────────────────────────────┤
│                         Footer                           │
│                    (版权 + 链接)                          │
└─────────────────────────────────────────────────────────┘
```

### 页面类型

| 页面 | 布局特点 |
|-----|---------|
| 首页 (home) | Banner + 文章列表 + 分页 |
| 文章页 (post) | 标题 + 元信息 + 封面图 + 正文 + 导航 |
| 归档页 (archive) | 年度时间线布局 |
| 分类页 (categories) | 卡片网格布局 |
| 标签页 (tags) | 标签云布局 |
| 关于页 (about) | 个人介绍 + 社交链接 |
| 404 页 | 星空动画 + 返回首页 |

### 响应式断点

| 断点 | 宽度 | 布局调整 |
|-----|------|---------|
| Mobile | < 768px | 隐藏导航，汉堡菜单 |
| Tablet | 768px - 1024px | 窄版内容区 |
| Desktop | > 1024px | 标准居中布局 |
| Wide | > 1400px | 最大宽度限制 800px |

### 预设主题

#### 1. 星夜 (Night) - 默认深色主题

```css
:root {
  /* 主色调 */
  --bg-primary: #0a0a0f;           /* 深空背景 */
  --bg-secondary: #12121a;         /* 卡片背景 */
  --bg-tertiary: #1a1a24;          /* 悬浮背景 */

  /* 文字色 */
  --text-primary: #e8e8ed;         /* 主文字 */
  --text-secondary: #8b8b99;       /* 次文字 */
  --text-tertiary: #5c5c6d;        /* 弱文字 */
```

## 星空元素

### 粒子背景 (Particles)

| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| `enable` | boolean | `true` | 是否启用 |
| `density` | number | `80` | 粒子密度 (1-200) |
| `color` | string | `#7c9cf0` | 粒子颜色 |
| `size` | number | `2` | 粒子大小 (1-5) |
| `opacity` | number | `0.6` | 透明度 (0-1) |

### 流星效果 (Meteor)

| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| `enable` | boolean | `true` | 是否启用 |
| `frequency` | number | `5` | 出现频率 (秒) |
| `color` | string | `#ffffff` | 流星颜色 |
| `length` | number | `100` | 流星长度 |

### 星座连线 (Constellation)

| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| `enable` | boolean | `false` | 是否启用 |
| `hoverShow` | boolean | `true` | 悬浮显示 |
| `lineColor` | string | `rgba(124, 156, 240, 0.5)` | 连线颜色 |
| `dotColor` | string | `#7c9cf0` | 节点颜色 |

### 月相图标 (Moon Phase)

| 配置项 | 类型 | 默认值 | 说明 |
|-------|------|-------|------|
| `enable` | boolean | `true` | 是否启用 |
| `position` | string | `header` | 显示位置 (header/footer) |
| `showTime` | boolean | `true` | 显示当前时间 |

## 动效设计

### 过渡动画

| 类型 | 时长 | 缓动函数 | 用途 |
|-----|------|---------|------|
| `fast` | 150ms | ease-out | 按钮悬浮、点击 |
| `normal` | 250ms | ease-out | 页面元素显示 |
| `slow` | 400ms | ease-in-out | 页面切换、模态框 |

### 滚动动画

- **淡入上移**: `translateY(20px) → translateY(0)`, `opacity: 0 → 1`
- **交错延迟**: 相邻元素间隔 100ms
- **触发时机**: 元素进入视口 100px 时

### 星空动效

- 粒子: 随机漂浮，速度 0.1-0.5px/帧
- 流星: 45度角划过，尾迹渐隐
- 星座: 悬浮时节点发光，连线渐显

## 交互规范

### 链接交互

| 状态 | 样式变化 |
|-----|---------|
| Default | `color: var(--accent-primary)` |
| Hover | `color: var(--accent-secondary)`, 下划线渐现 |
| Active | `opacity: 0.8` |
| Focus | `outline: 2px solid var(--accent-primary)` |

### 按钮交互

| 状态 | 样式变化 |
|-----|---------|
| Default | 背景透明，边框 `var(--border-primary)` |
| Hover | 背景 `var(--bg-tertiary)`，边框颜色加深 |
| Active | 缩放 `scale(0.98)` |
| Disabled | `opacity: 0.5`, `cursor: not-allowed` |

## 配置示例

### _config.yml

```yaml
# 主题配置
theme: almagest

# 布局设置
layout:
  type: centered  # centered | sidebar | wiki
  max_width: 800px

# 主题设置
theme_settings:
  preset: night  # night | aurora | aurora-green | hiiragi

# 星空元素
astronomy:
  particles:
    enable: true
    density: 80
    color: "#7c9cf0"
    size: 2
    opacity: 0.6
  meteor:
    enable: true
    frequency: 5
    color: "#ffffff"
    length: 100
  constellation:
    enable: false
    hover_show: true
    line_color: "rgba(124, 156, 240, 0.5)"
  moon:
    enable: true
    position: header
    show_time: true
```
